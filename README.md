# PROGETTO PAGINA WEB RESPONSIVE COMPLETA

🔗 **[Visualizza l'anteprima live del progetto (GitHub Pages)](https://gianluca-4.github.io/Responsive-Project/)**

Questo progetto è una versione rielaborata e ottimizzata del mio **Project Work universitario per la Laurea in Informatica**. L'applicazione originale è stata sottoposta a un processo di rebranding e pulizia dei riferimenti commerciali per renderla pubblicamente accessibile, mantenendo inalterata la struttura logica e funzionale.

La landing page è incentrata sul tema della sostenibilità aziendale per un'azienda fittizia. Per lo sviluppo è stata studiata una palette cromatica adatta al contesto ambientale, abbinata a una scelta tipografica coerente e altamente leggibile.

## Obiettivi del progetto
* **Responsive Design:** Dimostrazione della completa adattabilità del layout alle diverse risoluzioni di schermo (Mobile, Tablet, Desktop).
* **Gestione Risorse (Download):** Integrazione logica per il download dei report aziendali annuali in formato PDF, simulando l'interazione utente con un server di distribuzione.

## Caratteristiche del Codice
Il codice sorgente dei file HTML e CSS è interamente commentato e strutturato per favorire la massima comprensione e leggibilità da parte di chi consulta il repository.

## Tecnologie utilizzate
* **HTML5:** Strutturazione semantica dei contenuti.
* **CSS3:** Stilizzazione avanzata e layout.
  * Flexbox
  * Grid System
  * Media Queries (Responsive Design)

## Struttura del progetto
* `index.html` : File principale e punto di ingresso della pagina web.
* `style.css` : Foglio di stile associato per la gestione del layout e del design.
* `IMAGES/` : Cartella contenente gli asset grafici ottimizzati per il web.
* File PDF simulati dei report di sostenibilità.
